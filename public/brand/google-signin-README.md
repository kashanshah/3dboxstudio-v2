# Google sign-in asset

`google-signin-light.png` is the unmodified pre-approved Android + Web light, text, square button at 3× resolution (540×120), from Google's May 2026 asset bundle:

https://developers.google.com/static/identity/images/signin-assets.zip

Bundle path: `Android + Web/PNG @3x/Light/Theme=Light, Show text=Yes, Shape=Square, Platform=Android+Web@3x.png`

Branding guidance: https://developers.google.com/identity/branding-guidelines

The shared component displays the full button at a preserved 4.5:1 aspect ratio. Do not recreate the logo, recolor the image, or stretch it. The label remains available as image alt text. Authentication continues through the existing server OAuth flow, with a safe internal return path.
